วิธีใช้งานเว็บ เด็กรถขนส่งทั่วไทย ทรานสปอร์ต
=============================================
1. แตกไฟล์ zip แล้วดับเบิลคลิก index.html เพื่อดูเว็บในเครื่องได้ทันที
2. อัปโหลดทั้งโฟลเดอร์ขึ้นโฮสติ้ง (ไฟล์ index.html ต้องอยู่หน้าสุดของโฮสต์)
   ฟรี: Cloudflare Pages / Netlify / GitHub Pages
3. ค้นหาข้อความ https://www.example.com/ ในไฟล์
   index.html, robots.txt, sitemap.xml แล้วเปลี่ยนเป็นโดเมนจริง
4. ใส่รูปผลงานในโฟลเดอร์ images/ ชื่อ work-1.jpg ถึง work-6.jpg
5. ส่งเว็บเข้า Google Search Console และสร้าง Google Business Profile
